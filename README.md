## 10. Guidance for Lead Qualification & Proposal Preparation

When reviewing an Upwork job, identify:

1. **Business problem:** What process or functionality does the client need?
2. **Technology match:** Does the project use Laravel, React.js, JavaScript/TypeScript, PostgreSQL, or MySQL?
3. **Domain match:** Is the requirement related to ERP, inventory, POS, logistics, education, or a custom business application?
4. **Deliverables:** Does the client need a new application, a specific module, API integration, bug fixing, or optimization?
5. **Relevant experience:** Which project example or technical capability most closely matches the requirement?
6. **Scope and risks:** What information is missing, and what questions should be clarified before quoting a timeline or price?

**Proposal principle:** Focus on the client's specific problem, explain the relevant technical approach, and reference the closest matching experience. Avoid sending a generic list of technologies to every client.
